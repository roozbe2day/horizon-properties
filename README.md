# Horizon Properties — نسخهٔ آمادهٔ GitHub Pages

وب‌سایت واکنش‌گرا و دوزبانهٔ فارسی/انگلیسی است. این خروجی مستقل با HTML، CSS و JavaScript اجرا می‌شود و برای انتشار در GitHub Pages به Node.js یا فرایند build نیاز ندارد.

## انتشار در GitHub Pages

- فایل ZIP را باز کنید و **محتویات پوشه** را در ریشهٔ مخزن GitHub بارگذاری کنید؛ فایل `index.html` باید مستقیماً در ریشه باشد.
- در مخزن، وارد **Settings → Pages** شوید.
- در بخش Build and deployment، گزینهٔ **Deploy from a branch** را انتخاب کنید؛ شاخهٔ اصلی و مسیر `/(root)` را تنظیم و ذخیره کنید.
- پس از انتشار، نشانی GitHub Pages را باز کنید. مسیرهای داخلی با hash کار می‌کنند و به تنظیم سرور نیاز ندارند.

برای اجرای محلی، `index.html` را در مرورگر باز کنید. در صورت محدودیت مرورگر برای ویدیوهای محلی، پوشه را با یک وب‌سرور ساده اجرا کنید.

## ساختار صفحهٔ اصلی

Hero، **WHAT WE DO**، **ABOUT US**، **WHY HORIZON**، **FEATURED**، تیم، دعوت به تماس و فوتر.

## امکانات

- رابط فارسی راست‌چین و انگلیسی با کلید تغییر زبان.
- ویدیوهای Hero، About Us و Featured با کنترل اسکرول؛ بدون پخش خودکار یا تکرار و با امکان حرکت معکوس.
- نسخه‌های ویدیو و پوستر محلی، نسخهٔ سبک‌تر موبایل، تصویر جایگزین و پشتیبانی از کاهش حرکت.
- فهرست ملک‌ها با جست‌وجو، فیلتر و مرتب‌سازی؛ صفحهٔ جزئیات، گالری، علاقه‌مندی‌ها و ملک‌های مشابه.
- کاروسل قابل استفاده با لمس و ماوس، پیمایش صفحه‌کلید و کنترل‌های دسترس‌پذیر.
- صفحه‌های Home، Properties، Property Detail، About، Services، Team و Contact.
- طراحی واکنش‌گرا، بارگذاری تنبل تصاویر، چیدمان RTL و مسیرهای نسبی مناسب مخزن‌های GitHub.

## فایل‌ها

- `index.html` — ورودی کامل وب‌سایت.
- `404.html` — مسیر جایگزین برای GitHub Pages.
- `assets/css/site.css` — ظاهر، چیدمان و واکنش‌گرایی.
- `assets/js/site.js` — ترجمه‌ها، داده‌های نمونه و تعامل‌ها.
- `assets/images/` — تصاویر ملک‌ها، تیم و پوسترهای ویدیو.
- `assets/videos/` — ویدیوهای بهینه‌شدهٔ دسکتاپ و موبایل.

## نکته‌های پیش از انتشار

اطلاعات ملک‌ها، شمارهٔ تلفن، ایمیل و نشانی فعلی نمونه هستند؛ پیش از انتشار آن‌ها را با اطلاعات واقعی جایگزین کنید. فرم تماس برنامهٔ ایمیل کاربر را با متن آماده باز می‌کند. ثبت خبرنامه فقط در حافظهٔ مرورگر همان کاربر ذخیره می‌شود و برای ارسال واقعی باید به یک سرویس خبرنامه متصل شود.
